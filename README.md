# 親分ダーツ (Oyabun Darts)

A joke darts app where a crime boss picks today's data-breach target. All companies are fictional.

情報漏えいが「日替わり」状態な昨今、犯罪結社の親分がダーツで次の標的を決めていそう、という妄想をアプリにしたものです。

## 遊び方

モードは3つ。盤は本物と同じ20分割（上から時計回りに 20, 1, 18, 4, 13…）で、各番号に架空企業が割り当てられています。

- **今日の標的**：高速回転するボードに一投。回転中はドラムロール、刺さると減速して標的を発表。ダブルは被害×2、トリプルは×3、ブルは業界まるごと
- **カウントアップ**：1ラウンド3投×8ラウンドの合計点。1点＝1万件の流出換算。最高1440点。「投げる人」を子分テツ（元プロ）にすると、8ラウンド自動で投げてくれる（ブル狙いの定石どおり）
- **01（501）**：親分が子分のヤスに課したノルマ501万件を、ヤスがぴったり0にしたら上がり。超えたらバースト（やりすぎて足がつく）。最大15ラウンド

カウントアップと01では、盤をタップした所を狙って投げます。「調子」（絶好調／ふつう／二日酔い）で手ブレの大きさが変わります。ブルはソフトダーツと同じく50点。

アワード：LOW TON（100〜150点）、HIGH TON（151点以上）、HAT TRICK（ブル3本）、TON 80（T20×3）、THREE IN A BED（同じ所に3本）。

## 動かし方

`index.html` をブラウザで開くだけ。ビルド不要、外部依存は Google Fonts のみ。

## 注意

ジョークアプリです。登場する企業・団体・事件はすべて架空で、実在のものとは一切関係ありません。
